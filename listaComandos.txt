git clone: Sirve para copiar o descargar un repositorio remoto a tu computadora local.

git commit: Sirve para guardar los cambios realizados en el área del repositorio.

git push: Sirve para subir los commits locales al repositorio.
git status: Muestra el estado de los archivos en el directorio de trabajo y el área de preparación.
git add: Sirve para añadir archivos o cambios.
